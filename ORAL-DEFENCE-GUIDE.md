# Group oral-defence rehearsal

Every member should be ready for any question; this is not a claim of individual contributions.

1. Trace customer -> site -> installation -> equipment placement. Explain why placement is a separate table.
2. Explain the composite installation-technician key and maintenance's reference to a service assignment.
3. Show an example partial dependency removed in 2NF and a transitive dependency removed in 3NF.
4. Run an INNER JOIN and a LEFT JOIN; explain why zero-assignment technicians must remain visible.
5. Explain invoice line price versus catalogue price, and receipts versus accrual revenue.
6. Trace the installation procedure: validation, locks, placements, equipment status, installation status, commit. Explain the 38/41 rollback test and the four ACID properties without claiming untested concurrency or crash results.
7. Explain why status precedes scheduled_at in the scheduling index and why EXPLAIN costs are estimates.
8. Distinguish root, solargrid_app, solargrid_report and individual application roles. Demonstrate denied UPDATE.
9. Explain snapshot data loss, separate restore targets, protected hashes and recreation of database grants.
10. Explain a possible NoSQL store for variable telemetry/inspection documents while MySQL remains authoritative for payments and allocations.

Before assessment, practise modifying a filter or aggregate query and locating the source code that handles a failed operation. Keep a working local copy and the tested backup available. Do not reset the demonstrated database just to repeat a recording.
