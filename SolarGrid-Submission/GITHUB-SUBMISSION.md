# GitHub submission steps

1. Sign in to your group's GitHub account and create a repository called SolarGrid-IT212-Group1 (suggested name). Use private access while preparing the submission; give the lecturer access as required by the course.
2. Upload the CONTENTS of SolarGrid-Submission, preserving the folders. Include README.md, the technical report, final presentation, SQL folders, app source, normalization and evidence. A repository with only a ZIP is harder to review; upload the actual source files.
3. Do not upload .venv, .env, passwords, cache files or the recovery SQL dump to a public repository. The supplied .gitignore excludes those patterns; the separate recovery archive is for controlled handover.
4. Add recordings only after checking for visible passwords or unrelated personal content. Large videos can be provided through the lecturer's accepted sharing method with access enabled for assessment. Add their links to the repository README.
5. Open the repository in another signed-in browser session and confirm the report opens and source folders are accessible. Ensure the lecturer can access private files. Submit the repository link through the specified course channel before 12 October 2026.

Publishing has not been performed by the assistant. Repository URL and recording links are still to be supplied by the group. Every student must attend and participate in the live demonstration; videos are supporting evidence.
